SECOND LAND — САЙТ ДЛЯ GITHUB PAGES

ФАЙЛЫ
- index.html       структура страницы
- styles.css       дизайн и адаптация под телефон/компьютер
- script.js        одна настройка ссылки Telegram
- assets/          изображение для первого экрана

ПЕРЕД ПУБЛИКАЦИЕЙ
1. Открой script.js.
2. Найди строку: const TELEGRAM_URL = "https://t.me/+p5Xw3fURT_MxN2My";
3. Замени адрес на реальную ссылку своего канала, например https://t.me/+p5Xw3fURT_MxN2My.
4. Сохрани файл.

КАК ЗАГРУЗИТЬ НА GITHUB
1. Создай новый репозиторий на GitHub (или открой нужный).
2. Распакуй ZIP-архив на компьютере.
3. Загрузи ВСЁ содержимое папки secondland-github-site в корень репозитория.
   В корне должен лежать index.html, а рядом styles.css, script.js и папка assets.
4. На GitHub открой Settings → Pages.
5. В разделе Build and deployment выбери Deploy from a branch.
6. Выбери ветку main и папку /(root), затем Save.
7. Подожди несколько минут — GitHub покажет адрес опубликованного сайта в Settings → Pages.

ПРИМЕЧАНИЯ
- Сайт адаптируется под мобильные устройства.
- Кнопки Telegram в трёх блоках используют одну ссылку из script.js.
- В блоке доверия нет выдуманных отзывов, цифр и рейтингов. Когда появятся настоящие отзывы, их можно добавить.
- Для загрузки не нужно менять имена файлов и структуру папок.
