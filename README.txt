SECOND LAND — АДАПТИВНЫЙ ЛЕНДИНГ ДЛЯ GITHUB PAGES

СОДЕРЖИМОЕ
- index.html — три последовательных блока: знакомство, преимущества, отзывы и финальный CTA.
- styles.css — адаптивный дизайн для компьютеров, планшетов и телефонов.
- script.js — единая ссылка Telegram для всех кнопок.
- assets/hero-clothes.png — отдельное фото одежды для первого экрана (не скриншот постера).

ВАЖНО ПРО ОТЗЫВЫ
В третьем блоке добавлены три демонстрационных примера карточек отзывов, чтобы показать утверждённую структуру и дизайн. Тексты прямо помечены как примеры. Перед рекламным запуском замени их на реальные отзывы клиентов; не выдавай демонстрационные тексты за настоящие.

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Распакуй ZIP.
2. Загрузи содержимое папки secondland-github-site в корень репозитория. В корне должны лежать index.html, styles.css, script.js и папка assets.
3. Если GitHub спросит о замене файлов — подтверди замену.
4. Открой Settings → Pages.
5. Выбери Deploy from a branch, ветку main и папку /(root), нажми Save.
6. Дождись успешной публикации в Actions.
7. Открой сайт в приватном окне или обнови его сочетанием Ctrl+F5.

Ничего не переименовывай и не загружай папку secondland-github-site целиком внутрь другой одноимённой папки.
