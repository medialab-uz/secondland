# Secondland landing page

Адаптивный одностраничный сайт с блоками преимуществ, шагов, отзывов и кнопками перехода в Telegram.

## Файлы
- `index.html` — готовая страница сайта.
- `secondland-landing.png` — изображение для первого экрана.

## Загрузка на GitHub Pages
Загрузите `index.html` и `secondland-landing.png` в корень репозитория. В GitHub откройте Settings → Pages и выберите публикацию из ветки `main`, папка `/(root)`.

Все основные кнопки уже ведут в Telegram-канал Secondland.

Отзывы на странице — демонстрационные тексты, созданные для макета. Перед публичным размещением замените их на реальные отзывы участников или удалите блок.
