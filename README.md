# SecondLend — готовый сайт для GitHub Pages

## Файлы проекта
- `index.html` — главная страница.
- `styles.css` — адаптивные стили.
- `script.js` — меню, cookies, Meta Pixel и события Telegram-кликов.
- `config.js` — Telegram-ссылка и Meta Pixel ID.
- `privacy.html` — политика конфиденциальности.
- `favicon.svg` — иконка сайта.
- `robots.txt` — правила для поисковых роботов.
- `.nojekyll` — отключает обработку Jekyll для статических файлов.

## Важно
Карточки в разделе впечатлений содержат демонстрационные тексты и прямо помечены как примеры, а не реальные отзывы. Контакт `hello@secondlend.uz` — заглушка; замените его на свой адрес в `config.js` перед публикацией либо измените контактный блок.

## Загрузка на GitHub
1. Распакуйте архив.
2. Откройте папку с файлами.
3. Загрузите ВСЁ содержимое этой папки в корень репозитория (там, где уже лежит `index.html`), а не сам ZIP и не папку целиком.
4. Подтвердите `Commit changes`.
5. В репозитории откройте Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
